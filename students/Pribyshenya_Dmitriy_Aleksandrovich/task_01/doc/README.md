## Пошаговая инструкция по сборке и запуску

### Предварительные требования
- Установлен Docker Desktop (4.76.0 или новее)
- PowerShell или CMD

### Шаг 1: Перейти в папку проекта
```powershell
cd students/PribyshenyaDmitry/task_17/src
```
### Шаг 2: Запустить BAT-файл
Дважды кликнуть по `start.bat` в проводнике **или** выполнить:
```powershell
.\start.bat
```
### Шаг 3: Выбрать действие в меню
```
╔════════════════════════════════════════╗
║           ГЛАВНОЕ МЕНЮ                 ║
╠════════════════════════════════════════╣
║  [3] Собрать и запустить (рекоменд.)   ║
╚════════════════════════════════════════╝
Выберите действие (0-13): 3
```
BAT-файл автоматически:
- Соберёт Docker-образ
- Запустит оба контейнера (app + redis)
- Дождётся готовности
- Выполнит health check
- Откроет браузер с приложением

### Шаг 4: Проверить работу
- **Главная страница:** http://localhost:9051
- **Health check:** http://localhost:9051/ready
- **API:** http://localhost:9051/api/info

### Шаг 5: Остановить сервисы
В меню BAT-файла выбрать:
```
[5] Остановить (graceful shutdown)
```
Или выполнить вручную:

```powershell
docker-compose down
```

### Другие полезные команды меню
| Пункт | Действие |
|-------|----------|
| `[1]` | Только сборка образа |
| `[2]` | Только запуск сервисов |
| `[7]` | Просмотр логов приложения |
| `[9]` | Проверить статус контейнеров |
| `[10]` | Тестировать все API endpoints |
| `[12]` | Посмотреть размер образа |
```
