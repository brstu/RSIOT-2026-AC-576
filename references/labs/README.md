# Выжимки лабораторных

`lab_NN_summary.md` (~150 строк каждая) появляются здесь по мере доработки
лабораторных `tasks/task_01..04` по очереди из `docs/План_генерации.md`.

Формат summary:

- Тема и артефакт лабы (1–2 строки)
- Лекции-основы
- Что студент делает по шагам (кратко)
- Слоты стандарта: быстрый первый успех, «зачем в реальных системах»,
  раздел «использование ИИ», механизм пересдачи
- Критерии оценивания (кратко)
