# Лаба 01 — выжимка

**Тема:** контейнеризация сервиса «СмартДом» (Docker). Переработана по
стандарту university-teacher 09.08.2026; старые файлы —
`curriculum/archive_2025/task_01/`.

## Суть и артефакты

Студент пишет мини-сервис на паре сущностей «СмартДома» (Python 3.12/FastAPI
или Node.js 22), упаковывает в multi-stage образ (≤ 150 МБ, числовой non-root
UID, HEALTHCHECK exec-формой без curl) и поднимает стенд `compose.yaml`
(сервис + Redis/PostgreSQL + volume). Сдаёт в
`students/<NameLatin>/task_01/{doc,src}` через PR + 2 ревью.

## Критерии (100 + 15 бонусов)

Образ 30 · compose-стенд 25 · сервис/graceful shutdown 15 (это ключевые, 70) ·
метаданные/именование 15 · отчёт по макету 10 · документация 5.
Бонусы: digest-пиннинг+скан 5, битва за размер 4, JSON-логи/metrics 3,
автоматизация 3. Пересдача: < 85 % по ключевым (< 60 из 70) → доработка и
повторная защита.

## Слоты стандарта

Быстрый первый успех — запуск `examples/` за 15 минут (PowerShell,
Invoke-RestMethod); «Зачем в реальных системах» — таблица в README + раздел
в макете (пишет студент); «Использование ИИ» — можно/декларировать/запрещено,
защита по своему коду; рейтингов нет.

## Варианты и примеры

`Варианты.md`: 1–45 — архив прошлых наборов (аддитивно сохранены), 46–70 —
«СмартДом» для АС-576: пара сущностей + сценарий + стек/порт/зависимость/
UID/тег. Вариант 0 = `examples/`: телеметрия Device+Reading на FastAPI +
Redis; собрано и прогнано (образ 101 МБ, healthy, 503 без Redis,
volume-персистентность, SIGTERM → exit 0).

## Связь с лекциями

Лекция 01 — словарь сущностей, частичные отказы (503 вместо падения), ретраи;
лекция 02 — слои/кэш, тег vs digest (крючок Trivy 03.2026), non-root,
HEALTHCHECK, Compose v2 (`compose.yaml` без `version:`). Мост дальше: лаба 2
возьмёт этот образ в Kubernetes (лекции 16–18).
