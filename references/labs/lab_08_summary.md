## examples/ («СмартДом», вариант 0)

`prefix=smarthome_, slo=99.9%, p95=300ms, alert="5xx>1% за 10м"`:

- `app/server.js` — Node.js/Express ingest-reading: counter
  `smarthome_readings_total{type,status}` (нормализация type против
  кардинальности), histogram `smarthome_ingest_duration_seconds`, gauge
  `smarthome_hub_connections`, `/metrics`, ENV STU_*, `FAULT=1` —
  имитация 503 для демонстрации алерта; package.json, Dockerfile
  (multi-stage, non-root).
- `helm/smarthome-app/` — чарт: deployment/service/servicemonitor
  (label `release: monitoring`!)/prometheusrule (алерты error-rate и
  p95 из values). `helm lint`/`helm template` — PASS (WSL helm 3.21).
- `dashboards/queries.md` — PromQL трёх панелей + burn rate из
  лекции 24 + сценарий проверки срабатывания алерта (FAULT=1).
