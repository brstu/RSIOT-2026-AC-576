## Состав

- `readme.md` — README со всеми метками (`artifacts`/`criteria`/`bonuses`),
  4 части задания, лекции-основы новой сетки, правила ИИ и пересдачи 85 %.
- `QUICK_START.md` — winget-установка kubectl/kind, первый под, частые
  проблемы (ImagePullBackOff → kind load и т.п.).
- `Макет_отчета.md` — титул БрГТУ-2026, таблица критериев = README,
  разделы «Зачем в реальных системах» и «Использование ИИ» (заполняет
  студент), 10 контрольных вопросов.
- `Варианты.md` — 45 параметрических вариантов (ns/имя/порт/реплики/
  ресурсы; ingressClass — только для бонуса; тип Service по чётности).
- `examples/` — вариант 0: FastAPI-сервис телеметрии (`/readings` с
  Idempotency-Key, `/health/live`, `/health/ready` с прогревом, `/stats`),
  Dockerfile multi-stage на python:3.12-alpine (non-root, <150 MB),
  манифесты k8s: namespace smartdom, ConfigMap (ALERT_THRESHOLD_C),
  Secret (заглушка), Deployment (2 реплики, RollingUpdate 0/1, пробы,
  ресурсы, preStop), Service ClusterIP 80→8080.

## Задание (4 части)

1. Быстрый первый успех (30–40 мин): kind create + деплой эталона.
2. Свой образ: multi-stage, ≤150 MB, non-root, health-эндпоинты, STU_*.
3. Манифесты по варианту: Deployment/Service/ConfigMap/Secret (+Ingress
   бонусом).
4. Проверки: endpoints, слом readiness, rollout undo со скриншотами RS.
