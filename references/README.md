# Референсы курса РСиОТ

Компактные выжимки для генерации материалов без чтения полных текстов лекций
и лаб (экономия контекста 70–80 %). Стандарт скилла
`bstu-shared:university-teacher`.

| Файл / каталог | Назначение |
| --- | --- |
| `course_reference.md` | Общий референс курса (~200 строк): цели, план, стек, палитра, терминология |
| `lectures/lecture_NN_summary.md` | Выжимка лекции NN (~100 строк) |
| `labs/lab_NN_summary.md` | Выжимка лабораторной NN (~150 строк) |

## Правила

- При доработке/создании лекции N читать `course_reference.md` +
  `lectures/lecture_01..N-1_summary.md`.
- При доработке/создании лабы K читать `course_reference.md` +
  `labs/lab_01..K-1_summary.md`.
- Полные тексты предыдущих материалов **не** читать.
- После каждого доработанного материала — сразу создавать/обновлять его summary.
