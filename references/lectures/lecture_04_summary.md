## Ключевые концепции (введены здесь)

- Нет общего «сейчас»: дрейф кварца (десятки ppm), clock skew,
  синхронизация всегда с погрешностью; одновременность узлов ненаблюдаема.
- Лестница синхронизации: NTP/chrony (мс) → PTP (мкс, аппаратный
  таймстампинг) → Amazon Time Sync (мкс как сервис) + ClockBound (интервал).
- Время прыгает назад: NTP-step, leap second (смеринг; отмена к 2035),
  пауза/миграция VM.
- Два вида часов: time-of-day (метки «когда было») vs монотонные
  (таймауты, backoff-паузы, метрики — ТОЛЬКО монотонными).
- LWW = «большая метка побеждает», не «последняя запись»: при skew молча
  теряет свежие данные (Cassandra, aphyr).
- Happens-before (→): один процесс, сообщение, транзитивность; всё
  остальное конкурентно (∥) — порядка не существует.
- Часы Лампорта: `L=max(L,T)+1`; A → B ⇒ L(A) < L(B), **обратное неверно**;
  полный порядок — пары (L, id).
- Векторные часы: V(A) < V(B) ⇔ A → B; несравнимость = конкурентность;
  цена O(N). Выбор победителя — отдельное решение (merge/юзер/CRDT).
- Гибриды обзорно: HLC (CockroachDB/Mongo), TrueTime (интервал +
  commit wait; куплено GPS/атомными часами).
- Event time vs ingest time; дедупликация — ключом, не меткой; конкурентные
  тревоги не выстраивать в ложную хронологию.
