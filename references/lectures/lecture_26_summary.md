# Лекция 26 — выжимка

**Тема:** производительность и масштабирование: клюшка задержки, законы
Амдала/USL, нагрузочное тестирование (k6 как SLO-гейт), автоскейлинг,
защита от перегрузки, кэш, GPU-нагрузки. Сырьё — старая «Лекция 24»
+ load-часть старой «Лекции 25» (обе в `archive_2025/`). Файл —
`curriculum/Лекция_26_Производительность_и_масштабирование.md`.

## Ключевые концепции (введены здесь)

- Четыре прибора: задержка p95/p99, throughput, утилизация,
  **насыщение**; **хоккейная клюшка** — у края ёмкости задержка
  нелинейна (через Литтла L=λW); здоровая утилизация 60–75 %.
- **Амдал** S(N)=1/((1−p)+p/N): потолок задаёт последовательная доля;
  **USL** добавляет штраф когерентности (~N²) — кривая масштабирования
  загибается **вниз** (почему нет Raft на 99 узлов). Мораль: уменьшай
  последовательную долю и координацию до умножения узлов.
- Нагрузочные тесты: smoke/load/stress/soak/spike (spike = Эрас-тур);
  **k6 thresholds** кодируют SLO в тесте, ненулевой exit = гейт CI
  (скрипт slt.js в лекции). Грабли: ноутбук с шумными соседями,
  сравнение средних, без прогрева, стенд ≠ прод.
- Масштабирование: вертикально (просто, потолок, SPOF) vs
  горизонтально (stateless + цена координации). **HPA** (пример YAML:
  cpu 70 %, stabilizationWindow 120с; без requests — слеп; CPU не та
  метрика для IO), **KEDA** (по длине очереди, до нуля — мост к л.23).
  Автоскейл приложения не масштабирует базу.
- Защита от перегрузки (пик > любой автоскейл): rate limiting (token
  bucket, 429, центральные счётчики), backpressure (очередь + 202; зал
  ожидания Ticketmaster), load shedding (приоритеты: тревога дыма >
  телеметрия), + circuit breaker (л.9).
- Кэш: TTL всегда; инвалидация проектируется до внедрения;
  **cache stampede** лечится single-flight + джиттер TTL (вторая
  работа джиттера из л.1). Кэш не чинит медленный алгоритм.
- GPU/AI-нагрузки: GPU дорог и неделим → **батчинг** (капля задержки
  за кратный throughput), тяжёлый холодный старт → scale-to-zero
  выключен; очередь + батч + скейл по очереди. Тизер FinOps (л.27).

## Слоты

- **Крючок:** Ticketmaster / Eras Tour 15.11.2022 — 3,5 млрд
  запросов/день (×4 пика), 14 млн желающих на 2,4 млн билетов, боты
  ×3, продажи остановлены — `sources/Веб-находки_Лекция_26.md`.
- **Квиз-извлечение:** по лекции 25 (киты zero trust, base64/слои
  защиты секретов, supply chain/Shai-Hulud, SBOM/SLSA/подпись).
- **PI-1:** p95 80→900 мс при CPU 35 %; верный C (найти узкое место:
  трейсы, насыщение); дистракторы: удвоить реплики / поднять лимиты /
  кэш без диагноза.
- **Живой сеанс:** «волна 03:00» — 100 000 Hub'ов одновременно:
  джиттер расписания → кэш общего прогноза (TTL+джиттер) → очередь+202
  и KEDA-воркеры → k6-spike как регресс-гейт (mermaid в лекции).
  Пойнт: убрали причину пика, а не залили железом.
- **Мост:** лаба 8 = стенд лекции (гистограмма — датчик клюшки; k6 +
  FAULT=1 против своих дашбордов и алертов).
