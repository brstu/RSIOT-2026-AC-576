# Лекция 17 — выжимка

**Тема:** сетевые основы для РС: путь запроса — DNS, TLS, HTTP/1.1→2→3,
балансировка L4/L7, облачные сетевые мелочи. Написана как новая; старый
файл (история IP, gRPC, ретраи — ушли в л. 3) — в `archive_2025/`.

## Ключевые концепции (введены здесь)

- Путь запроса: DNS-резолв → соединение + TLS (QUIC: TLS внутри) →
  HTTP → балансировщик → здоровый бэкенд. Аналогия: звонок в компанию.
- Стек уровней как метод диагностики «делить проблему пополам»; MTU 1500,
  туннели его съедают (тизер л. 20).
- DNS: иерархия (кэш ОС → резолвер → корень → зона → авторитетный), типы
  записей (A/AAAA, CNAME, MX, TXT, NS), TTL. **Миф «пропагации»**: DNS
  кэшируется (pull), не рассылается; миграция = заранее понизить TTL.
  GeoDNS как первый эшелон балансировки.
- TLS: шифрование + аутентификация; сертификат, цепочка доверия, CA, SNI;
  TLS 1.3 = 1-RTT; ACME/Let's Encrypt; 0-RTT только идемпотентным.
- HTTP: HOL blocking спускается по этажам — 1.1 (приложение) → 2
  (транспорт TCP) → 3/QUIC (потоки независимы). QUIC: миграция соединения
  (Wi-Fi→LTE), поверх UDP из-за ossification. HTTP/3 = 21–39 % трафика
  2026, >50 % топ-1000; включать на внешнем крае, fallback обязателен.
- Балансировка: L4 (соединения) vs L7 (запросы, маршрутизация, TLS-
  терминация); round robin / least connections / consistent hashing;
  health checks с гистерезисом («нет ответа» = «неизвестно»). Глобальная:
  GeoDNS, anycast, edge (Front Door/CloudFront); вход = концентрированное
  место отказа, конфиг входа катят как код.
- Мелочи: port exhaustion (~16 тыс. эфемерных портов), MTU в туннелях
  (`ping -f -l 1472`), ретраи на границе → ключи идемпотентности.
