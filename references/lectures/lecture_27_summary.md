## Ключевые концепции (введены здесь)

- CapEx → OpEx: счёт стал функцией архитектуры — инженер может его
  программировать. FinOps = Inform → Optimize → Operate; бюджет затрат
  = error budget денег (рифма с л.24).
- Анатомия счёта: compute / storage / network / managed; **egress —
  сюрприз № 1** (входящий бесплатен, исходящий и межрегиональный —
  нет; кейс «80 % счёта — трафик»). «Каждая стрелка на диаграмме имеет
  цену».
- **Юнит-экономика**: счёт ÷ бизнес-единица (на дом, на тысячу
  распознаваний) — мост инженерия↔бизнес. **TCO** своего железа:
  серверы + люди + ДЦ + простои + упущенная эластичность; правило
  л.23: рваное → облако, ровное → резервации/своё железо.
- Видимость: теги в IaC (стандартизация, без тегов — не проходит
  ревью), showback → chargeback, Kubecost для K8s, бюджеты + алерты
  аномалий (финансовый burn rate).
- Покупка мощности: on-demand (валюта гибкости) / reserved-savings
  30–70 % (предсказуемость; резервируют **базу**, не пик) / spot
  60–90 % (прерываемость; для того, что переживает смерть узла —
  связь с л.9).
- Данные: температура → классы hot/warm/cold/archive,
  lifecycle-политики, агрегация старой телеметрии; грабли archive
  (достать дорого); CDN снижает egress (л.23).
- **AI-затраты (State of FinOps 2026)**: 98 % управляют, 73 %
  превысили AI-бюджет, утилизация GPU 15–30 %, **80–90 % затрат —
  инференс**. Пять рычагов: батчинг (л.26), кэш результатов, каскад
  моделей, фильтр до GPU, committed+spot; юнит-метрика «стоимость
  тысячи распознаваний».

## Слоты

- **Крючок:** исход 37signals (3,2 млн $/год AWS → серверы 600 тыс.,
  окупаемость < 18 мес, S3 → Pure, аккаунт удалён, > 10 млн $ за
  5 лет) с контрапунктом: у них ровная нагрузка — лозунг «облако —
  обман» не следует — `sources/Веб-находки_Лекция_27.md`.
- **Квиз-извлечение:** по лекции 26 (утилизация 60–75 %, USL, k6
  thresholds, батчинг GPU).
- **PI-1:** база 10 подов + пики до 30; верный C (резервация базы +
  пики on-demand/spot); дистракторы: всё on-demand / reserved на пик /
  всё spot.
- **Живой сеанс:** юнит-экономика «СмартДома»: 40 000 $/мес ÷ 100 000
  домов = 0,40 $; раскладка по статьям (GPU 35 %) → два рычага
  (фильтр+батчинг GPU 14 000→5 000; lifecycle+агрегация 8 000→4 500) →
  0,27 $ (−33 %) → бюджет-алерт. Ход: статьи → юнит → рычаги →
  пересчёт → алерт.
- **Мост:** к лекции 28 — «у каждой девятки есть цена» (DR-стратегия =
  цена часа простоя против цены страховки); в лабе 8 — Kubecost-панель
  рядом с p95.

## Примеры «СмартДома»

Раскладка счёта по статьям, стоимость на дом, каскад «человек/кот»,
lifecycle фото с камер, spot для ночного переобучения.
