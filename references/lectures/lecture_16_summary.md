# Лекция 16 — выжимка

**Тема:** облачные модели и провайдеры: NIST-определение, IaaS/PaaS/FaaS/SaaS,
модели развёртывания, shared responsibility, большая тройка, регионы/зоны,
экономика облака. Написана как новая по стандарту university-teacher; старый
конспект — `curriculum/archive_2025/Лекция_16_...md`.

## Ключевые концепции (введены здесь)

- Облако = 5 признаков NIST: самообслуживание, сетевой доступ, пул ресурсов,
  эластичность, измеряемость; CapEx → OpEx. Контрпримеры: «сервер под
  столом», «виртуалка по заявке за 3 дня».
- Лестница моделей обслуживания IaaS → PaaS → FaaS → SaaS: выше — меньше
  контроля и меньше эксплуатации; это компромисс, не рейтинг. Cold start FaaS
  (тизер лекции 23).
- Модели развёртывания: публичное / частное / гибрид / мульти-облако
  («настоящее» мульти дорого, у большинства — «случайное»).
- **Shared responsibility model**: провайдер — безопасность облака, клиент —
  безопасность В облаке; данные, доступы, бэкап-стратегия — клиента ВСЕГДА.
  Репликация ≠ бэкап (тиражирует и DROP TABLE). PITR.
- Регион / зона доступности; минимум продакшена — 1 регион, 2 AZ.
- Рынок Q1 2026 (Synergy): $129 млрд/квартал, AWS 28 % / Azure 21 % /
  GCP 14 % (63 %), AI-нагрузки 19 % расходов. Таблица эквивалентов сервисов.
- Экономика: egress ($0,05–0,12/ГБ), data gravity, vendor lock-in,
  on-demand/reserved/spot, репатриация.

## Примеры «СмартДома»

Телеметрия → PaaS-контейнеры; история → managed PostgreSQL (2 AZ + PITR);
прошивки → FaaS; GPU-видеоаналитика → IaaS; почта команды → SaaS;
видеоархив наружу = egress-ловушка.
