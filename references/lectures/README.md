# Выжимки лекций

`lecture_NN_summary.md` (~100 строк каждая) появляются здесь по мере
доработки лекций по очереди из `docs/План_генерации.md`.

Формат summary:

- Основная тема (1 строка)
- Ключевые концепции (только новые)
- Примеры на «СмартДоме» (краткое описание)
- Слоты: крючок, PI-вопросы, живой сеанс (что именно)
- Что студенты знают после этой лекции
- Связь с другими лекциями и лабами
