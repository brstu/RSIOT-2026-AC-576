# Лекция 12 — выжимка

**Тема:** очереди и стриминг: модели обмена, Kafka (партиции, группы,
offset), семантики доставки, DLQ, Schema Registry. Сырьё — старая
лекция 11 (совпадает), переплавлена в стандарт.
Файл: `curriculum/Лекция_12_Очереди_и_стриминг.md`.

## Ключевые концепции (введены здесь)

- **Брокер = почта**: развязка во времени, сглаживание пиков (буфер с
  retention, не бездонный — л. 9), fan-out.
- **Три модели**: очередь (RabbitMQ, потребил — исчезло), pub/sub,
  журнал (Kafka: записи живут до retention, читатели двигают offset) →
  **реплей** — суперспособность журнала.
- **Анатомия Kafka**: топик → партиции (единица параллелизма И порядка;
  л. 8 дословно); RF/ISR + acks=all (кворумы л. 6); **KRaft** — Raft-кворум
  метаданных (л. 7); Kafka 4.0 (03.2025): ZooKeeper удалён полностью.
- **Продюсер**: hash(key)→партиция; ключ = сущность, для которой важен
  порядок (readings → device_id); между партициями порядка нет; hot key;
  `enable.idempotence=true` + `acks=all` (ретраи не дублируют/не
  переставляют).
- **Консюмер-группы**: параллелизм ≤ числа партиций; несколько групп =
  fan-out; вход/выход = ребаланс (в классике stop the world); лекарства:
  static membership (`group.instance.id`), KIP-848 (Kafka 4.0,
  `group.protocol=consumer`, инкрементально, назначает брокер).
- **Семантики**: место коммита offset решает: до обработки = at-most-once,
  после = at-least-once (+идемпотентный потребитель л. 11);
  «exactly-once» с внешним миром = at-least-once + идемпотентность;
  ловушка auto-commit (тихий at-most-once).
- **DLQ**: N попыток с backoff → readings.dlq; poison message без DLQ
  останавливает партицию; DLQ под мониторингом.
- **Schema Registry**: версии схем (Avro/Protobuf/JSON), BACKWARD;
  продолжение «схема должна быть явной» из л. 10.

## Слоты

- **Крючок:** rebalance storm — rolling restart 240 консюмеров / 360
  партиций → 9 минут stop-the-world; лечение static membership (30+
  ребалансов → 0) — `sources/Веб-находки_Лекция_12.md`.
- **Квиз-извлечение:** по л. 11 (dual write, in-doubt, компенсация,
  outbox+relay).
- **PI:** лаг при 6 консюмерах на 6 партициях; верный B (узкое место
  обработки); дистракторы: +6 консюмеров (простой + ребаланс), чаще
  коммитить, 60 партиций.
- **Живой сеанс:** проектирование топиков «СмартДома»: readings
  (7 дн) + alerts (30 дн); ключ device_id (home_id отвергнут — шоурум);
  12 партиций из расчёта 200К/20К; группы rule-engine / archiver→Cassandra /
  analytics→ClickHouse; связка со схемой л. 10.
- **Мост:** лаба 4 «Очереди и стриминг» (tasks/task_04, после л. 13) —
  прямая: телеметрия с HTTP на брокер, продюсер/группа/offset/дубли;
  л. 13 — event sourcing на реплее.
