# Лекция 07 — выжимка

**Тема:** консенсус и Raft на практике (etcd — сердце Kubernetes).
Переплавлена из старой `Лекция_06_Raft_подробно.md` (копия в
`curriculum/archive_2025/`) + §4–6 архивной `Лекция_05_Репликация_и_консенсус_обзор.md`.

## Ключевые концепции (введены здесь)

- Консенсус = общее решение при отказах; нужен для «маленьких критичных
  фактов» (лидер, эпохи фенсинга, локи/конфиг), не для телеметрии.
- FLP одним абзацем: safety гарантируется всегда, liveness — «почти
  всегда»; Cloudflare — потеря liveness при целой safety.
- Raft: роли F/C/L, термы («один голос за терм» → один лидер на терм —
  вот кто выдаёт эпохи), рандомизированные тайм-ауты против split vote
  (джиттер из л. 01); etcd: heartbeat 100 мс / election 1000 мс.
- Лог: AppendEntries с (индекс, терм) предыдущей записи → log matching;
  коммит = большинство (кворумная запись как закон, не опция); лидер
  коммитит подсчётом только записи своего терма.
- Безопасность выборов: голос только за кандидата с не худшим логом →
  leader completeness (правильный лог не доставляется — неправильный
  лидер не избирается).
- Три «не» Raft: кворум мёртв → стоп записи (CP); больше узлов =
  медленнее запись (нечёт 3/5, ≤7); византийское не покрыто; PreVote
  гасит вечных кандидатов.
- etcd 3.6: ревизии (монотонный номер = фенсинг-токен), watch, lease
  (TTL + keep-alive), election, lock; etcdctl-команды в лекции.
- Kubernetes: вся память control plane — etcd; потеря кворума =
  read-only control plane, поды живут (kubelet автономен); 3/5 узлов.
- «СмартДом»: 3 × rules-engine → лидер через etcd election, тревога
  «дым» ровно один раз; ловушка lease (зависший экс-лидер) → фенсинг:
  «lease решает, кто работает; фенсинг — кому верить».
- Paxos: две фазы, Chubby/Spanner; Raft выбран за понятность (эксперимент
  Онгаро на студентах); понятность — характеристика системы.

## Слоты

- **Крючок:** Cloudflare 02.11.2020 — полуживой свитч (LACP/BGP да, vPC
  нет), etcd без стабильного лидера, read-only, 6 ч 33 мин —

  brain/фенсинг, W+R>N ≠ линеаризуемость, «мёртв vs медленный»).

  полностью); дистракторы: «почти половина — стоп», «коммиту нужны все»,
  «подтверждения умерли с узлами».
- **Живой сеанс:** выборы на 5 студентах — heartbeat-хлопки, смерть
  лидера, split vote, изолированный одиночка крутит термы (≈ узел 1
  Cloudflare, лечит PreVote).
- **Мост:** лекция 08 (партиционирование; «кто владеет шардом» — снова
  факт для консенсуса) + лаба 3 (election для «ровно одной» тревоги).
