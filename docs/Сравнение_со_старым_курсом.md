# Сравнение свежей сетки РСиОТ-2026 со старым курсом (curriculum 2025)

Дисциплина спроектирована как новая (шаг 0 скилла university-teacher —
актуализация тем), затем свежий список сопоставлен с 28 существующими
лекциями (29 файлами) в `curriculum/`. Старые файлы — сырьё; ничего не
удаляется: перед заменой файл уходит в `curriculum/archive_2025/`.

## Вердикты

- **Совпадает** — тема живая, старый текст пригоден как сырьё, добавить слоты
  стандарта и презентацию.
- **Переработать** — тема живая, но текст требует структурной работы
  (ужать/расширить/актуализировать), сырьё используется частично.
- **Устарела/лишняя** — в свежую сетку не входит; файл остаётся в архиве.
- **Темы не хватало** — в старом курсе отсутствовала, пишется с нуля.
