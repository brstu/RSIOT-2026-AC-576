## Регламент (по навыку `bstu-shared:university-teacher`)

Один материал — один заход (борьба с context rot). Для лекции NN свежей сетки:

1. Прочитать `references/course_reference.md` + summary всех предыдущих
   лекций (`references/lectures/`); полные тексты не читать. Старую
   лекцию-сырьё (по таблице сравнения) читать можно — это источник.
2. **Резервная копия**: затрагиваемые старые файлы → `curriculum/archive_2025/`.
3. **(а) Лекция пишется как новая** по `references/lecture.md` скилла:
   живое повествование + слоты — крючок (реальный инцидент; веб-поиск:
   1 заход, 2–4 запроса; находки → `sources/Веб-находки_Лекция_NN.md` с URL
   и датой), квиз-извлечение по предыдущей паре, 1–2 PI-вопроса с разборами,
   ровно один живой сеанс, квиз-закрепление, мост к лабе, глоссарий, ответы.
   Мини-примеры — на «СмартДоме». Пригодное сырьё старой лекции —
   переплавлять в повествование, не вставлять списками.
4. **(б) Презентация** по `references/presentation.md`:
   `scripts/presentations/build_presNN.js` на каркасе `deck_common.js`
   (палитра «Океан») → `curriculum/Презентация_NN_<Тема>.pptx`. Сборка — во
   временном каталоге (EBUSY), копия на место последним шагом. После сборки —
   маркеры `> 🖥 **Слайды N–M.**` в лекцию.
5. **GATE (NEVER SKIP)**: markdownlint → 0; Mermaid построчно;
   `verify_presentation.py` → 0; OOXML-валидатор (`PYTHONUTF8=1`) → PASS;
   PowerPoint COM: открыть + экспортировать ВСЕ слайды в PNG; просмотреть
   каждый PNG; прогон глазами студента-новичка; адверсариальное опровержение
   (≥3 находки или явный отказ); чек-листы lecture.md / presentation.md.
6. Создать `references/lectures/lecture_NN_summary.md`.
7. Обновить статус здесь. В git ничего не коммитить без команды преподавателя.

Для лабы KK — то же с `references/lab.md`: слоты «быстрый первый успех»,
«зачем в реальных системах», «использование ИИ», пересдача; «СмартДом» в
`examples/`; бэкап старых файлов лабы в `curriculum/archive_2025/task_KK/`;
summary в `references/labs/`.

**Нумерация файлов.** Новая лекция NN занимает имя
`curriculum/Лекция_NN_<Тема>.md`. Если под этим номером лежит старый файл
другой темы — он предварительно уходит в архив. До завершения очереди в
`curriculum/` сосуществуют старая и новая сетки; таблица соответствия —
в `docs/Сравнение_со_старым_курсом.md`.
