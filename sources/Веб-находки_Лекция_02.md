## 3. Типичные заблуждения новичков (→ дистракторы квизов и PI)

Ключевое: новички описывают контейнер как «лёгкую виртуалку» — Docker сам
воюет с этой рамкой («Containers are not VMs»; контейнер — процесс хоста
с изоляцией, а не машина с гостевой ОС). Следствия заблуждения:

1. «В контейнере есть своя ОС/ядро» — нет, ядро общее с хостом; в образе
   только user space (файлы, библиотеки).
2. «Контейнер сохраняет изменения как машина» — нет, writable-слой умирает
   с контейнером; состояние — в volume.
3. «EXPOSE открывает порт» — нет, это документация; порт публикует `-p`.
4. «latest = самая свежая и безопасная версия» — это просто тег по
   умолчанию, изменяемая метка (кейс Trivy: `latest` перезаписан малварью).
5. «Контейнеры небезопасны, потому что ядро общее» — управляемо: non-root,
   capabilities, seccomp, read-only FS.
6. «VM устарели, контейнеры их заменили» — нет, это разные уровни изоляции;
   Docker Desktop на Windows сам работает поверх VM (WSL2).
